# Little Flower Secondary School Website

Official website for **Little Flower Secondary School**, Birgunj-21, Parwanipur, Parsa (Estd. 2005).

## 🌟 Features
- **Hero Campus Photo Slider**: High-impact campus photo carousel with auto-play and manual navigation.
- **Academic Programs**: Curriculum details from Nursery/Kindergarten to SEE Board (Grade 10).
- **Modern Infrastructure**: Physics, Chemistry & Biology science labs, computer ICT center, sports ground, and auditorium.
- **Faculty Leadership**: Educator directory with credentials and messaging modal.
- **Notice Board & Events Calendar**: Searchable official circulars and RSVP program registrations.
- **Transport Routes**: School bus coverage across Parwanipur, Gandak, Birgunj Ghantaghar, Murli, Jitpur, and Pipra.
- **3-Step Online Admissions**: Digital application wizard with instant scholarship estimator and printable admission slip.
- **Student & Parent Portal**: Terminal marksheets, attendance tracker, exam routine, admit card download, and online fee payments.
- **Virtual Campus Tour**: 360° interactive campus explorer.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS v4 + Custom Light Red Theme
- **Icons & Animations**: Lucide React + Canvas Confetti + Motion

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone or navigate to the repository
cd "Little Flower"

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
